# GPT HUD 3.1.3 — 정식 초기화 시각 표시

## 범위와 기준

기준은 공개 정식3.1.2, commit `e052f8845b6fdfa6543e9b4896a1231ccc535e18`, package `dev.bennett.codexmeter`, code89다. 베타9.9.11 기능은 이미 정식3.1.1에 통합됐고3.1.2는 같은 정식의 업데이트 주소 전환이었다. 새 통합/이전/베타 재명명 설계를 중단하고 초기화 시각 표시를 기존 정식에 적용한다. 이후 최신 직접 요청에 따라 아래의 미배포 한마디 검토본도 포함했다.

정식3.1.3/code90. 기존 서명/패키지/인증/DB/성장/설정을 유지한다. Wear/Windows 버전과 원본을 유지한다. 최신 직접 사용자 요청 “미배치 한마디 검토본도 이번에 같이 반영해서 업데이트하고”에 따라 검토된 한마디 코드·카탈로그를 포함한다. 기존 stable-3.1.1의 원본13파일과 beta-9.9.11-release 작업은 원래 경로에 보존한다.9.9.14 신규 베타는 게시하지 않았다.

## 변경

- `BetaQuotaUi.java`: 메인에서 숨기던 초기화 줄을 표시한다. 기존 snapshot epoch와 `UsageFormat.absolute/compactDuration`을 사용해 현지 날짜·시각과 남은 시간을 두 줄로 구분한다.360dp 미만 또는 큰 글자에서는 세로 배치한다. 미제공/오래된 관측/조회 실패/시각 경과를 구분하며 새 관측 없이100%로 만들지 않는다.
- `MainActivity.java`, `HomeInsightClock.java`: 기존 로컬 표시 타이머를 가까운 리셋/만료 경계에 맞추고 pause/stop/destroy 이후 늦은 콜백을 막는다. 네트워크 수집·새 알림·백그라운드 API를 추가하지 않는다. 티어·한도 → 중앙 한마디 → 주간 사용량 배치를 반영하고 한마디 cacheKey를 갱신 가드에 포함한다.
- `CoachUi/FunHome/SpicyQuotes/CoachCatalog`와 두 카탈로그: 검토된 중앙정렬·전체 문장 줄바꿈·한국식 친구 말투200수정/424유지,624안정ID/40팁/끄기·숨김 보존. 문구 편집·추가·수동 교체 없음. 기존에 검증된 오래된 worker/지난 reset 방어도 포함한다.
- `home_quota_strings.xml` 한국어/영어: 날짜·시각과 남은 시간 문장만 추가한다.
- app Gradle/AppConstants/build.sh/CHANGELOG/release-history: 정식 버전·code·기록을 맞춘다. README에 정식 단일 신규 배포와 베타 종료 안내를 추가한다.
- 신규 focused source/release/formatter 검사: 이전 fixture를 수정하지 않고 정식3.1.2 대비 정확한 변경 파일·바이트와 업데이트 호환성을 검사한다. 기존 CI의 역사적3.1.1 gate는 파일을 보존하고3.1.3에서는 새 변경 범위 gate를 사용한다. 이전 전체 검사를 새로 통과했다고 주장하지 않는다.

## 검증과 한계

실행: `verify-home-reset.py`180검사, `verify-stable313-release.py`17개 합성 업데이트 검사, `verify-stable313-source.py`843생산파일 검사(기존12파일/신규3파일만 변경), 한마디 검수·선택기/만료 경계 검사, Release 빌드/lint, 최종APK의 기존 서명·패키지·code·폰트/라이선스 검증. 공개 후 동일 생산 parser로 실제 API의3.1.3 발견과 다운로드/SHA256SUMS 일치를 별도 확인한다. 최종 공개 결과와 해시는 배포 영수증에 기록한다.

동일 시간 표시의 베타 로컬 후보에서180포맷/137native검사가 앞서 통과했다. 이 결과를 이번 정식 APK의 새 native검증으로 부르지 않는다. 이번 정식 회차에서 릴리스 안내 수정과 에뮬레이터 실행을 묶은 명령이 자동 승인 검토에 의해 `blocked by policy`로 실행 전 거부됐으며 구체적인 사유는 제공되지 않았다. 에뮬레이터 실행은 재시도하지 않았다. 안내 파일은 명시적 개별 패치로 수정했다. 정식의 새 native/에뮬레이터 설치·시스템 설치/실기기/실계정/실사용 데이터/TalkBack/OEM 장기 동작은 미검증이다. 속도 설정은 조회 기능이 없어 직접 확인하지 못했고 변경하지 않았다.

## 설치·베타 종료

기존 정식: 기록→설정→앱 정보→업데이트 확인. 자동 확인/알림은 기존 사용자 설정과 주기를 따른다. APK는 앱에서 다운로드 후 Android 동의로 설치하며 자동 설치됐다고 추정하지 않는다.

기존 베타는 별도 패키지다. 정식 APK를 별도로 설치하고 로그인해야 하며 기존 베타 데이터를 삭제/초기화하지 않는다. 기존 성장/설정 백업은 일부 항목만 지원하고 로그인·사용량 전체 이력을 옮기지 않는다. 두 앱의 기록이 자동 병합되지 않는다. 대규모 이전 기능/강제 제거/사용자 데이터 변경을 수행하지 않았다. 이전 베타 릴리스/산출물은 복구 가능성을 보존한 종료 처리만 수행한다.
