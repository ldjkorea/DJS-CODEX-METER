# GPT HUD 3.0.0 통합 정본

2026-10-14 / 로컬 릴리스. Android 및 Wear `3.0.0 / versionCode 85`, Windows Widget `3.0.0`.

## 통합 범위

현재 정본 `95a4313`과 기존 미커밋 언어 선택 작업을 기반으로, 본부의 구버전 체크아웃·배포 자료·보고서를 비교했다. 2.8.6 체크아웃의 추적 파일 699개 중 515개, 초기 한국어판의 574개 중 434개가 현재 정본과 동일했다. 이전에 있던 Android 기능 파일의 누락은 없었으며, 변경된 기능의 보존은 기존 회귀 검사로 확인했다. 빠진 과거 보고서·CI 파일·참고 자료는 유지보수 이력에 보존했다.

- 사용량 조회, 관측 원장, SQLite 기록, 달력·추세, 결제 기간과 결산.
- XP·레벨·티어, 업적·칭호 수집, 대표 메달과 프로필 이미지 공유.
- 기존 13개 Android 위젯 Provider, Now Bar/AOD, Wear, Windows 및 LAN/Tailscale 연결.
- 2.9.2의 시작 잠금 수정과 2.9.3 개발본의 한국어·영어 선택 및 번역 리소스 경량화.
- 기존 서명, 패키지, 데이터 형식과 인증/업데이트 안전 장치.

구버전 소스를 새 코드 위에 덮어쓰지 않았다. 구버전 Git 참조는 현재 `.git`의 `refs/legacy/next/*`, `refs/legacy/original/*`에 보존했다. 이 참조에는 과거 비공개 개발 이력이 있으므로 공개 원격에 `--mirror` 또는 `--all` 방식으로 업로드하지 않는다. 기존 회귀 검사 원본 fixture는 변경하지 않았다.

## 자료 정리와 복구

현재 소스, 라이선스, 원본 artwork, 회귀 fixture, 서명키 및 연결 경로는 통합판 유지에 필요하다. 별도 버전 APK, 옛 체크아웃, 중복 배포 묶음, 완료된 QA 빌드·가상기기 파일은 정리 대상이다. 고유 참고 자료와 이전 검증 증빙은 `.local-recovery/consolidated-inputs.zip`에 내용 해시별로 합치며 `INDEX-FINAL.json`에서 원래 경로를 찾는다. 최종 인덱스가 없으면 `INDEX.json`을 사용한다. 파일마다 저장 후 SHA-256을 재검증한다. 현재 소스와 같은 파일은 현재 파일 위치를 기록하며, Git 이력과 재생성 가능한 출력은 별도 판정한다.

`.local-recovery`는 로컬 유지보수 자료이며 Git 및 배포용 소스 ZIP에서 제외한다. 서명키는 `android/.local-signing`에 유지하며 배포 묶음에 포함하지 않는다. `.local-recovery/cleanup-plan.json`과 `cleanup-result.json`에서 삭제 범위와 실제 완료 여부를 확인한다. 이전 경로 호환용 정션은 현재 SOURCE에 연결된 항목이다.

## 남은 범위

실물 휴대폰의 2.9.2 설치본 위 업데이트와 실제 사용자 데이터 보존, Samsung 런처/AOD/Now Bar, Wear 실기기, 실계정 OAuth/API, 외부망 Tailscale은 이번 검사에 포함되지 않았다. 새 에뮬레이터의 합성 데이터만 사용했다. 공개 push·태그·GitHub Release·휴대폰 설치는 실행하지 않았다. Windows 실행 파일의 Authenticode 서명은 제공하지 않는다.

본부 표준 G드라이브 백업 호출은 자동 승인 검토에서 거부됐다. 소스·DB·세션·서명 자료를 외부 저장소로 보내는 구체적인 범위의 승인 부족이 사유이며, 호출 자체가 실행되지 않았다. 로컬 복구 자료의 검증과 외부 재해복구 백업은 구분한다.

## 정리 완료 및 독립 재검증

본부 안의 구버전·중간 산출물 **36,795개 / 31,115,996,833 bytes** 삭제 완료. 고유 자료 6,579개는 내용별 중복을 제거해 약 346MB의 로컬 복구 묶음으로 보존했다. 현재 서명키는 유지했다. 옛 `ARCHIVE`에는 현재 SOURCE를 가리키는 호환 정션만 남겼다.

정리 중 빌드 데몬이 lint 캐시를 잡고 있어 삭제가 한 번 중단됐다. 이번 빌드 데몬만 종료한 뒤 나머지를 삭제했고 최종 삭제 결과의 오류 목록은 비어 있다. 본부 밖 Documents의 `verified-old-20261014` 보관 경로는 이 작업의 삭제 범위에 포함하지 않았다.

구버전 폴더 삭제 후 전체 `android/run-tests.sh`가 다시 종료 코드 0으로 완료됐다. Phone/Wear는 프로젝트 빌드 산출물이 없는 상태에서 94개 Gradle 작업을 실행해 2분 36초 만에 재빌드했다. 두 APK의 모든 ZIP 내부 파일은 최초 결과와 같았다. 전체 APK 바이트는 서명 블록 때문에 다르며, 재빌드본도 같은 기존 인증서로 검증했다. 바이트 완전 동일이라고 주장하지 않는다.

현재 다시 생성된 `android/build`, 모듈별 `build`, `.gradle`은 이 독립 검증으로 생성된 3.0.0 관련 산출물이다. 폐기한 옛 버전 복사본이 아니다. 검증 로그는 `delivery/3.0.0/verification`에 모았다. 미커밋 상태의 기존 언어 작업을 포함해 현재 작업 트리를 보존했으며 이번 작업에서 Git 커밋·원격 push·태그를 만들지 않았다.
