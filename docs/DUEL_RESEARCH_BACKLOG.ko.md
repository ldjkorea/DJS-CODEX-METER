# DUEL 연구 백로그 — 정식 개발 보류

이번 버전에는 DUEL 코드·서버·친구 관계·리더보드를 구현하지 않는다. 개인 사용량의 많고 적음으로 AI 실력을 판정하지 않는다.

## 연구할 최소 방식

두 사람이 같은 공개 또는 합성 미션, 동일 입력 자료, 시간 범위와 허용 도구를 합의해 결과물을 만든다. 예: 작은 파서 구현, 합성 UI 개선, 동일 fixture의 오류 수정. 인증정보·실제 고객 자료·상용 원본 코드는 과제로 쓰지 않는다. 결과 공유는 참가자의 명시적 선택으로만 수행한다.

품질 평가 기준을 시작 전에 공개한다: 정답/테스트 충족, 요구사항 준수, 읽기 쉬운 결과, 접근성, 오류 처리. 맹검 검토와 독립 평가자를 우선하고 서로 다른 모델/요금제/PC 자원의 차이를 기록한다. 토큰 소비·사용 시간은 설명 자료이며 우승 점수가 아니다.

## 위험과 보류 조건

- 같은 미션이라도 모델 권한, 도움받은 사람, 기존 코드 재사용 차이로 공정성이 달라진다.
- 자동 AI 심사도 일관성/비용/프롬프트 편향을 검증해야 하므로 이번에 도입하지 않는다.
- 친구 계정 한도·프로젝트 이름·원본 대화·경로·결제정보를 수집하지 않는다.
- 품질을 판정할 신뢰 가능한 기준이 없으면 승패 대신 참가자의 피드백만 남긴다.
- 경쟁을 위해 의미 없는 토큰 낭비, 구독 업그레이드, 야간 활동을 유도하지 않는다.

## 작은 실험

동의한 2명, 공개 합성 미션 1개, 사전 채점표, 로컬 결과물만으로 수동 비교한다. 계정 연동/실시간 매칭 없이 익명 A/B 결과를 검토한다. 참가자의 삭제·공유 범위를 시작 전에 합의한다. 만족도, 평가 일치도, 준비/검토 시간, 개인정보 노출 여부를 기록한다. 실험도 별도 사용자 승인 뒤 진행하며 이번에는 수행하지 않았다.

유효한 공정성·품질·개인정보 근거가 생길 때만 후속 개발 여부를 판단한다.
