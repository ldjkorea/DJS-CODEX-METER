## 승인과 기준

2026-10-17 사용자가 구현·검증·베타 배포를 명시했다. 기준 공개 소스 b9fa5b513a5af83379aaf65dd570acf88b65dd10 (9.9.8). beta/9.9.9, beta-v9.9.9 prerelease만 게시하며 정식 3.1.0/main/latest·서명·사용자 기기·실계정은 유지한다. 이전 작업 폴더의 Git 연결 대상이 없어 현재 공개9.9.8에서 새 전용 clone을 만들었다. 이전 폴더/자료나 정본의 미커밋 작업은 변경하지 않았다.

## 변경 계획과 구현

1. 티어 휘장·색상·이름·칭호·레벨/XP·5시간/주간 남은 한도를 하나의 카드에 배치한다. 비동기 프로필 완료는 내부 슬롯만 교체하므로 한도가 사라지지 않는다. 실패 시 캐시 프로필을 보존한다.
2. 바로 아래 이번 주간 사용량. 서버가 제공한 현재 주간 사용률과 초기화 주기를 표시하며 달력 주간과 혼동하지 않는다. 일별 막대는 같은 KST 날짜/정책/초기화 주기/정상 관측 쌍의 증가량만 보여준다. 누락은 —, 예정은 예정, 실제 관측0은0. 기간 경계·공백·보정·구독 변경·legacy를 추정 배분하지 않는다. Free 월간 한도를 주간으로 바꾸어 표시하지 않는다.
3. 홈 ‘지금 할 일’과 중복 한도 개요 제거. 목표/성장/회고는 기존 성장·기록 화면에서 유지. AI 한마디600/팁40·자동선택·끄기/숨김·편집/추가/수동교체 제외 정책은 그대로다.
4. 새 주간 DB reader는 작업 스레드에서 현재 주기의 SELECT만 실행한다. OPEN_READONLY, 최대20000행, 한도 초과 시 부분 결과를 표시하지 않는다. 홈 렌더에 네트워크 잠금·DB이관·전체이력 스캔이 없다. 계정/스냅샷/관측 서명로 늦은 UI 결과를 버린다. 기존 로그인/설치기/성장 저장소와 경제/문구 자산은 바이트 동일 검사를 한다.
