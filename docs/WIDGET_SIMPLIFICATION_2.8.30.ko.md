삼성 10종은 `SamsungLockWidgetSupport`의 공통 렌더러·설정 구조를 재사용합니다. 서로 다른 계산 엔진이 10개 있는 것이 아닙니다. 정사각형/가로형, 단일/두 한도는 용도가 다르고 링/다이얼/막대는 같은 정보를 표현하는 선택지입니다. 앱의 추천 화면에서 고급 영역으로 분류했으며 **Android 시스템 위젯 목록에서 숨기거나 Provider를 제거하지 않았습니다**. 향후 통합은 설치 ID와 호스트별 이전 검증을 선행해야 합니다.

## 선택·설정

- 기록 → 설정 → 위젯 및 화면 → 위젯 선택에서 사용량 2×1과 작업현황 5×3를 먼저 안내합니다. 기존 위젯별 설정으로 바로 이동합니다.
- 미리보기는 실제 RemoteViews 레이아웃을 사용하며 테스트값임을 표시합니다. 실제 계정의 관측이나 실통신 화면이 아닙니다.
- 진화형·잠금화면은 접힌 고급 선택지로 이동합니다. 설정 창은 표시 항목 → 사용량/잔여량 → 배경/강조색/휘장 → 탭 동작 순으로 정리하고 레이아웃/테마는 펼쳐 봅니다.
- 표시 순서·개별 색상·투명도·퍼센트 기호·휘장·클릭 설정을 유지합니다. 화면에 없는 밀도/표면/갱신 표시 등 기존 필드를 저장 때 강제로 기본값으로 바꾸지 않습니다. 회전 중 편집값도 복원합니다.

## 신뢰성과 상태

- 사용량 원본·소수점 계산은 그대로입니다. 서버가 정수만 보내면 소수점도 0으로 표시됩니다. 값을 새로 추정하지 않습니다.
- 조회 실패 또는 관측이 오래되면 마지막 저장값의 상태를 함께 표시합니다. 원래 0×0 크기라 보이지 않던 작은 위젯의 상태 문구를 실제 공간에 배치하고 내용을 겹치지 않게 조정했습니다.
- 작업 전송은 기존 최대 6개 계약 그대로입니다. 실행 → 중단/확인된 명령·도구 오류 → 완료 순으로 정렬하되, 재전송 검증용 수신 순서는 바꾸지 않습니다.
- 실행은 녹색, 턴 완료/중단은 빨간색, 연결 실패/2분 초과/미확인은 회색입니다. 명령 하나의 오류를 작업 전체 실패로 바꾸지 않습니다. 전체 이름·오류는 기존 상세 화면에서 확인합니다.
- PC 인증·계정 검사·LAN/Tailscale 전송·개인정보 필터는 유지합니다. 승인·입력 대기는 현재 수집기에서 보내지 않으므로 새 상태를 지어내지 않았습니다.

## 갱신·성능

| 경로 | 실제 정책과 이번 개선 |
| --- | --- |
| 기본 사용량 | 기존 자동/수동 RefreshScheduler 공유. Provider 자체 주기 0. 반복 새로고침 탭은 5초 동안 합쳐 추가 조회를 줄임 |
| 작업현황 | 실제 설치 + 시험 ON일 때만 기존 15분 JobScheduler. 상세 화면이 열려 있을 때 15초 확인. 홈 백그라운드 15초 상시 조회를 보장하지 않음 |
| 작업 내용 동일 | 상태·작업명·오류·연결·마지막 확인 분이 같으면 비트맵 재렌더 생략. 4~6번째 작업 변경도 감지 |
| PC 끊김 | 실패 즉시 회색. 정상 수신의 신선도가 끝나면 로컬 비기상·비정확 알람으로 한 번 다시 그림. 추가 HTTP 없음, Doze에서 지연 가능 |
| 진화형 | 기존 15분/초기화 시각 로컬 타이머 유지. 겹치던 OS 30분 갱신 제거, 마지막 인스턴스 삭제 시 타이머 취소 |
| 삼성 잠금화면 | 기존 OS 30분·공통 사용량 업데이트, 설치된 ID에만 렌더. 미설치 Provider를 위한 별도 네트워크 Job 없음 |
| Windows / Wear | Windows 실행본·공개 ZIP 0.1.9 유지. Wear는 공유 계약 보존, 앱과 버전/빌드 호환 검사만 수행 |

배터리 절감량·장기 Doze·실사용 메모리 감소를 측정했다고 주장하지 않습니다. 위 내용은 코드의 주기 작업 수·중복 렌더 의사결정 및 에뮬레이터 검증 근거입니다.

## 검증 경계

기존 분리 QA 에뮬레이터 패키지에 v2.8.29를 설치한 상태에서 사용량/작업/진화형 ID와 옵션을 저장하고 v2.8.30으로 비파괴 업데이트합니다. 실제 사용자 앱에는 합성 데이터나 테스트 계정을 넣지 않습니다. RemoteViews 크기 변경·상태·설정/복원·가이드 Activity는 운영 앱과 같은 소스 경로를 실행합니다. 실제 삼성 홈/AOD·갤럭시 설치/로그인·PC↔폰 실통신은 별도 미검증입니다.

전체 테스트·빌드·서명·공개 파일 검증의 최종 결과는 배포 파일 `VERIFICATION.ko.md`에 기록합니다. v2.8.29의 별도 공개 배포는 없습니다.
