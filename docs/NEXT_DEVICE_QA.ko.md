# 차기 후보 실기기 수동 QA

아래 체크는 **아직 NOT VERIFIED**다. 에뮬레이터와 합성 테스트 성공으로 체크하지 않는다. 운영 사용자 DB를 테스트 도구로 열거나 수정하지 않는다. 앱 삭제/초기화로 설치 문제를 해결하지 않는다.

## 출시 후보 준비

- [ ] 승인된 신규 버전/code가 공개 2.8.51/81보다 높은지 검사
- [ ] 설치본 패키지와 서명 인증서 일치 확인
- [ ] 사용자 선택으로 안전한 암호화 RPG 백업 확보; 암호를 기록/공유하지 않음
- [ ] 기존 수집 ON/OFF, 대표 메달, 칭호, XP, 결제 기간, 위젯 배치 상태를 사용자가 화면에서 확인
- [ ] 제거 없이 Android 시스템 업데이트 설치 및 취소 경로 확인

## 삼성 갤럭시

- [ ] 실계정 로그인/토큰 갱신/사용량 수신; 한도 미제공과 조회 실패 구별
- [ ] 홈·기록·성장 및 계정 변경 직후 이전 계정 정보가 남지 않음
- [ ] v51 이후 새 후보에서 업적·칭호의 일회성 초기화가 재발하지 않음
- [ ] 월간 결산/XP/최고 티어/메달 선택/장착 칭호 보존
- [ ] Samsung 홈 위젯·잠금화면/AOD·Now Bar 갱신 및 크기 조절
- [ ] 320/360/411dp 수준, 큰 글꼴, 한국어/영어, 라이트/다크, 회전, TalkBack 확인
- [ ] 실제 Wear 타일/통신/표시 및 이전 설정 보존

## 프로필 공유

- [ ] 성장 → 프로필 공유, 기본 익명/날짜 OFF 확인
- [ ] 자신의 휘장·레벨·선택한 메달 최대 3개·칭호가 미리보기와 동일함
- [ ] 메달/칭호 없는 상태, 긴 닉네임, 1.5/2.0 글꼴, 화면 회전
- [ ] 시스템 문서 선택으로 원하는 폴더에 PNG 저장·취소·권한 실패
- [ ] Quick Share/카카오톡 등 실제 대상에 사용자가 직접 공유하고 수신 이미지를 확인
- [ ] 메뉴만 열거나 취소했을 때 전송 완료로 표시하지 않음
- [ ] 계정 교체 후 이전 미리보기 제거, 진행 중 파일 선택 후 계정 변경 시 이전 카드 저장 차단
- [ ] Android 최소 지원 버전부터 최신 버전까지 content URI/임시 읽기 권한 확인

PNG에 넣은 닉네임·성취는 이미지 내용이다. 한 번 다른 앱으로 넘기거나 저장한 이미지는 GPT HUD가 회수할 수 없다. 보낼 곳과 닉네임은 사용자가 직접 확인한다.
