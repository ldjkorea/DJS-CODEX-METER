# GPT HUD 2.8.25 검증 보고서

## 결과와 범위

Android 2.8.25 / versionCode 55, 패키지 `dev.bennett.codexmeter`. 기존 한국어판 인증서로 휴대폰·Wear Release를 빌드했습니다. 공개 v2.8.23 / 53에서 업데이트하고, 테스트 전용 에뮬레이터에서 삭제 후 같은 합성 계정으로 로그인 상태를 구성하여 암호 백업을 복원했습니다. 실제 갤럭시·개인 계정 OAuth/API·사용자 DB 복구를 수행한 결과는 아닙니다.

공개 배포 전 최신 원격 main과 v2.8.23을 다시 확인합니다. v2.8.24, 중간 공개 APK, 중간 태그는 만들지 않습니다. 실제 배포 후 다운로드 증거는 별도의 로컬 `android/build/refinement-release/PUBLICATION_READBACK.json`에 저장합니다.

## 데이터 보존

- 성취 DB는 기존 SQLite 스키마 1을 유지합니다. XP, 업적 53개의 ID·조건·보상·진행량·최초 획득일, 칭호, 대표 메달 순서, 티어 최고 기록, 결제 결산을 보호합니다.
- 대표 메달의 새 선택은 계정별 SQLite 문서에 저장하며 기존 Preference 선택도 읽습니다. 기존 설정·OAuth·사용량 원장·위젯 데이터는 초기화하지 않습니다.
- 기록 → 설정 → 성취 백업·복원에서 `.gpthud` 파일을 저장/가져옵니다. AES-256-GCM 및 PBKDF2-HMAC-SHA256 600,000회, 무작위 salt/nonce, 인증된 형식 헤더를 사용합니다. 암호와 인증 토큰은 파일에 저장하지 않습니다.
- 같은 계정 해시·형식·53개 업적·보상·결제/관측 자료를 검사한 다음 복원 전 사본과 새 문서를 트랜잭션에 기록합니다. 손상·다른 계정·SQL 실패 시 기존 문서를 유지합니다.
- 반복 복원은 XP를 더하지 않습니다. 최신 성취와 명시적 장착 해제/선택을 보존하며 원래 획득일을 유지합니다. 복원된 획득 근거는 `verified_trusted_journal`로 표시되므로 원본 JSON 전체 문자열 동일성 대신 성취 필드와 복원 출처를 각각 검사합니다.
- 명시적 삭제 시점 이전 원시 관측의 재유입을 막습니다. 보존 결산과 새로 확인된 소비를 분리하여 중복 합산을 방지합니다.
- 이 기능은 성취·결제 결산 백업입니다. 로그인, 전체 앱 설정, 사용량 원장 원본 전체, Windows 연결 정보의 완전한 기기 이전 기능은 아닙니다. 새 기기에서는 같은 계정으로 다시 로그인해야 합니다.

## 평가·가성비·성장

- 실제 원장 재조정/토큰 수신 경로에서 강등 평가를 실행합니다. 최신 자료, 같은 정책, 서울 시간대와 계정 전체 범위, 완전한 날짜/주간 증명이 부족하면 보류합니다. 확인되지 않은 날짜를 0으로 만들지 않습니다.
- 2개 유효 주간 저활용은 내부 경고, 3개 이상 연속 저활용과 장기 점수 하락이 함께 확인될 때 최대 1단계 강등합니다. 승급 후 2주 보호와 최고 등급은 유지합니다.
- 현재 수집기가 완전한 날짜 범위를 인증하지 못하면 실제 계정의 강등은 안전하게 보류됩니다. 인증된 합성 자료로 운영 진입점의 평가·강등 실행을 검증했습니다. 실제 사용자 강등이 발생했다고 주장하지 않습니다.
- 상위 승급에는 충분한 최근 완전 주간과 활동 근거를 요구합니다. 잠정 평가·누락 근거를 상세 화면에 표시합니다. 대한민국/세계는 독립된 게임형 추정이며 실제 이용자 순위가 아닙니다.
- 기존 XP와 레벨 곡선·일일 상한을 유지합니다. 확인된 토큰 이정표 100만/1천만/1억/10억/100억에 25/75/250/1,000/1,500 XP를 버전별 ID로 한 번 지급합니다. 공식 총계와 로컬 세션 토큰을 합산하지 않습니다.
- 기존 53개 업적·연결 칭호를 보존하고 독립 칭호 10개를 추가했습니다. 새 조건은 확인 가능한 활동·기존 메달·완전 주간의 조합이며 구독 변경이나 야간 사용을 요구하지 않습니다.
- 결제 시작~갱신일 기준 결산을 유지하고, 요금제 변경 이전의 같은 진행 기간 결산도 별도로 표시합니다. 서로 다른 통화·한도 정책을 무리하게 합산하지 않습니다. 참고 환산액은 실제 API 청구액·절약액이 아닙니다.

## UI와 실제 화면 검사

성장 카드의 고정 300dp 높이를 제거하고 기본 2열, 큰 글꼴에서는 세로 배치를 허용했습니다. 대표 메달은 가로 3열, 도감은 상태 필터를 먼저 보이며 카테고리·정렬은 접습니다. 칭호 보관함은 보유 우선·미리보기 후 명시적 장착을 유지합니다. 기존 메달 53개의 문양을 안정적인 ID에 고정하고 일부 희귀 문양을 개선했습니다.

실제 배포 패키지의 화면을 다음 16가지 조합에서 렌더링했습니다: 폭 320/360/411/700dp × 글꼴 1.0/1.5 × 한국어/영어, 다크 테마. 성장, 대한민국/세계 상세, 레벨 상세, 요금제 비교, 도감, 복합 메달 상세, 대표 메달 편집, 칭호 목록·미리보기, 백업 화면을 열고 실제 버튼을 검사했습니다. 752개 검사와 176개 조합별 캡처를 보존했습니다. 일부 샘플은 [화면 자료](refinement-2.8.25/)에 있습니다.

실제 Activity 재생성에서 필터/정렬과 미저장 대표 메달 선택이 유지되는지, 취소 후 기존 선택이 유지되는지 확인했습니다. 신규 업적 배너, 재진입 시 반복 방지, 효과 OFF도 검사했습니다. 시스템 애니메이션 OFF에서는 효과 동작을 줄입니다. 모든 회전 자세·실제 TalkBack 서비스·라이트 테마를 이 결과로 대체하지 않습니다.

## 발견한 실패와 처리

- 이전 소스의 Debug 데모 생성자 인자 누락: 필요한 인자만 보완하여 Debug 빌드 통과.
- 암호 형식 헤더의 소수 값이 정수로 잘릴 수 있음: 정확한 정수형 버전/반복 횟수만 허용하고 거부 검사 추가.
- 320dp/영문/큰 글꼴의 칭호 상태 글자 줄바꿈: 상태 폭 조정 후 실제 렌더링 재검사.
- 네이티브 복원 검사가 화면용 요약을 전체 문서로 읽고 출처 문자열도 그대로 비교함: 전체 저장 문서의 53개 성취 필드·획득일과 검증된 복원 출처를 각각 검사하도록 수정. 데이터를 삭제하거나 달성 기준을 바꿔 통과시키지 않음.
- 호스트 메모리 경합 중 일부 첫 진입이 5초 한도를 초과(약 5.1~7.9초)했고 System UI ANR가 문서 선택을 막음. 실패 로그·화면을 보존하고 이번 작업 AVD만 재시작한 뒤 재검사. 5초 기준을 완화하지 않음. GPT HUD 충돌로 확인된 경우는 없었으나 실제 단말 속도 개선을 입증한 결과도 아님.

합성 성장 곡선 검사: 1/30/90/365 활동일에서 1,470/4,950/12,150/45,150 XP, 레벨 5/10/16/30. 이는 제한된 상한 시뮬레이션이며 모든 요금제·장기 휴식 사용자 유형의 실제 밸런스를 입증하지 않습니다.

## 미검증 및 실사용 시 확인

실제 삼성 기기 업데이트·로그인/API, 실제 개인 DB 복구/27억 토큰 집계, 실기기 홈 위젯/Wear/AOD/Now Bar/Tailscale 연결, Doze·자정 장시간 동작, OEM 파일 공급자, 실제 TalkBack, 장시간 메모리 누수·실기기 성능은 이번 결과로 보증하지 않습니다. 기존 기능의 소스·자동 회귀와 Android 에뮬레이터 검증을 분리합니다.

업데이트 후 기존 로그인·XP·대표 메달·칭호를 먼저 확인하고 성취 백업 파일을 별도 위치에 보관하세요. 문제 발생 시 앱 삭제/데이터 초기화 대신 기존 데이터를 유지하고 증상을 확인하세요. 암호를 잊으면 암호 백업을 복원할 수 없습니다.
