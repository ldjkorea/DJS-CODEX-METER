# GPT HUD 3.1.0 — 정식 업데이트

베타9.9.6에서 검수한 홈·성장·개인화·설정 개편을 기존 정식 앱으로 통합했습니다. 베타 앱·beta/9.9.6·beta-v9.9.6은 별도로 유지합니다.

## 주요 변경

- 홈의 기존10티어 휘장·프레임·색상을 복구하고 이름·장착 칭호·레벨·경험치를 한 카드에 배치했습니다. 등급 자료가 없으면 배치 중입니다. 대한민국/세계 표시는 기존 고정 기준 등급이며 실제 사용자 순위표로 표현하지 않습니다.
- 명예37개·칭호24개를 제공합니다. 기존16개의ID/조건을 유지하고 확인3/14/30일 등 가까운 목표, 주간·월간, 중간 레벨과 장기 목표를 추가했습니다. 새 수집품은 확인된 기존 새-growth 기록에서 계산하며 추가 XP는 지급하지 않습니다.
- 기록·홈·성장 내비게이션, KO/EN·큰 글씨 대응, 이름을 넣는 안정된 칭호, 네 그룹 설정, 직접 저장/공유하는 프로필 이미지, 계정별 백업 검증·병합 복원을 통합했습니다. 기존 세부 도구·위젯·Wear·Windows·사용량·결제·계정 기능은 유지합니다.
- 한마디600개와 실전 팁40개를 연결합니다. 한마디 → 한 수 써먹기 → 실전 프롬프트 → 직접 선택한 복사 흐름이며 보기·복사·다른 한마디·도감 탐색에는 XP/업적을 주지 않습니다. 새 AI API·대화 분석·클립보드 감시·분석 서버를 추가하지 않습니다.
- 새 사용자 최초 가입 완료 후 이름 설정은 선택/건너뛰기가 가능하며, 이미 가입한 사용자를 이름 설정으로 강제 이동하지 않습니다. 기존 언어 선택을 보존합니다.

## 기존 사용자 데이터와 새 성장

**업데이트만으로 새 성장을 시작하거나 기존 레벨/XP를 초기화하지 않습니다.** 배포된3.0.0의 RpgEngine·RpgArchive·ProfileCard 및 기존 SQLite 구조를 유지했습니다. 새 성장 시작을 앱에서 직접 확인하면 기존 계정의 RPG 내보내기를 별도 읽기 전용 보관함에 저장하고 새로운 rules4/usage-check-v4 성장만 Lv1/XP0으로 시작합니다. 기존 계정 DB·원본XP·레벨 내부 진행률·획득 날짜·장착·보관함·미래 확장 필드를 보존합니다. 새 성장이 활성화된 후 기존 RPG의 성장 보상은 고정하며 사용량·관측·등급 처리는 계속합니다. 새로운DB는 계정별 트랜잭션으로 처리하고 홈 렌더링은 작은 저장 요약만 읽습니다.

합성 실제 교체 예: 기존 **Lv31 / 원본XP46,539 / 내부 진행39÷3,100**을 유지하고 보관함에도 남깁니다. 새 성장 선택 후 별도 Lv1/XP0입니다. 9.9.6의 MXP 자동 이관 코드로 기존 정식 성장 엔진을 교체하지 않았습니다. 같은 계정/같은 증거/같은 기간 보상은 재시도·복원·재시작·24회 동시 재처리에서도 한 번만 지급됩니다.

| 목표 | 새 성장 누적 XP |
|---|---:|
| Lv30 | 232 |
| Lv40 | 1,082 |
| Lv50 | 5,332 |
| Lv100 | 40,332 |

2027·2028년 모든 시작 날짜에서 월~금 주5일 신선한 사용량 확인 성공을 반복하면 첫22~28일 안에 Lv30입니다. 실제 ChatGPT 일반 대화·업무 성과를 자동 인증한다고 주장하지 않습니다. 주간은 한국 시간 월~일, 월간은 달력 월입니다. 사용자 직접 기록과 API 확인 활동은 구분합니다.

## 정식과 베타의 분리

정식 package는 `dev.bennett.codexmeter`, OAuth 복귀는 `codexmeter://auth/complete`, 업데이트는 기존 한국어 저장소의 `v3.1.0`/`CodexMeter-3.1.0-ko.apk` 계약을 유지합니다. 베타의 가상 데모·trial launcher·인증 주소·업데이트 정책은 포함하지 않습니다. 내부 Beta로 시작하는 일부 클래스/DB 키는 검수한 구현을 재사용한 이름이며 별도 베타 APK가 정식 앱으로 설치되는 방식은 아닙니다. 정식과 베타의 앱 데이터는 Android 패키지별로 분리됩니다.

phone/Wear는 **3.1.0 / versionCode87**이고 Windows는3.1.0입니다. 과거 미공개code86 후보는 보존하고 이번 배포에 사용하지 않습니다. 기존 한국어 서명키를 유지했으며 새 키를 만들지 않았습니다. 기존 공개 정식3.0.0 code85에서 업데이트할 수 있습니다. Android 설치는 사용자의 확인을 거칩니다.

## 파일별 통합 이유

- BetaHomeUi/TierDialog/Ui/MatteNav: 원래 휘장·티어색·캐시 기반 홈과 산정 기준, 세 탭 및 큰 글씨 대응.
- BetaCatalog/Emblem/GrowthUi/Copy/V4/GrowthStore:37/24 수집품, 목표와 기간별 보상, SQLite와 증거·보상 중복 방지, 검증한 카탈로그2.
- BetaIdentity/Setup/NameDialog/SettingsUi/ProfileActivity/Archive/Backup: 선택적 이름 설정과 계정별 표시, 기존 도구 접근, 읽기 전용 이전 기록 및 명시적 저장/복원/공유.
- UsageApi/RpgProgressStore/RpgGrowthUi/ProfileShareActivity: 저장 성공 이후 새-growth 증거 연결, 선택 후 이전 성장 고정, 화면/프로필 연결. 기존 인증/업데이트/레거시 엔진은 유지.
- CoachCatalog/CoachUi/SpicyQuotes/FunHome:600문구/40팁, 설정/한도/안정ID/자료 부족과 사용자의 직접 복사 연결.
- 버전 상수·Gradle·Windows 메타데이터·release-history·테스트:정식code87과65개 오프라인 버전 안내, 해당 화면·버전 계약 검사.

## 실제 검증과 한계

- 현재 정식 소스 전체 run-release-validation: regression/localization/publication/public-source 통과. 원래 fixture/테스트를 삭제하지 않았고 lint baseline을 갱신하지 않았습니다. 버전/추가 릴리스 안내 및 위임된 홈/코치/설정 검사만 명시적으로 수정했습니다.
- 새 성장·카탈로그·보존1112개, 코치30466개 통과.10,000 작은 성장 요약은13ms(측정 환경 수치)였으며 네트워크/DB/전체 이력 작업이 없습니다.
- 소유한 합성 Android35 에뮬레이터에서 서명된3.0.0 code85→3.1.0 code86 후보 실제 교체70개 통과:원본 레벨/XP/진행률/획득·장착/다른 계정, 명시적 새 시작, 보관함, SQLite,24회 동시 처리, 백업 왕복·오류 거부, 실제 홈. 최종code87은 아래 최종 검증 결과와 릴리스의 VERIFICATION 문서로 구분합니다.
- 실제 화면297개 통과. 한국어·영어100/130/160/200%와200% 가로10조합을 검수합니다. 성능/접근성 검사는 합성 자료이며 실기기 성능·TalkBack 음성 검증을 대신하지 않습니다.
- Windows 컴파일/291개 검사/112개 화면 외 렌더 통과. 기존 Android/Windows 티어 팔레트·휘장 출처를 대조했습니다. 실제 로그인/레지스트리/운영 API를 호출하지 않았습니다.
- 별도 promotion guard로 인증·업데이트·레거시·위젯19개 핵심 파일 및 기존 launcher/permission/OAuth/Wear XML, 저장 성공 뒤의 단일 hook, 홈의 저장 요약 조회를 확인했습니다.

검수 중 기존 엔진의 관측시각/계산 메타데이터 갱신 때문에 전체JSON 비교가 실패했으며, 보존해야 하는 원본XP/진행률/획득·장착·기간 자료와 미래 확장 필드를 엄격히 비교하도록 고쳤습니다. 테스트의 원본 DB rpg 경로 가정도 수정하고 새로운 합성 AVD에서 실제 교체를 다시 검사했습니다. 최초 병렬 개별 스크립트 실행은 선행 JVM fixture 의존성이 있어 실패했고 기존 순서의 전체 회귀를 실행하여 통과했습니다. 이전 버전 수량/번호와 의도적으로 교체된 화면 위임에 관한 source guard도 해당 계약으로 수정했으며 역사 fixture는 재생성하지 않았습니다.

**미검증:** 사용자 실물 폰, 실계정 OAuth/서버 성공, 실사용 데이터 복원, TalkBack 음성, 모든 OEM/IME/위젯·Wear·Windows 물리 연결. 사용자 기기에 직접 설치·삭제·초기화하지 않았습니다. 서명·데이터·설정·원래 사용자 미커밋 작업 및 베타를 보존했습니다.
