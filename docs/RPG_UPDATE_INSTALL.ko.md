# GPT HUD 2.9.2 설치·업데이트

앱을 열자마자 멈춘다면 휴대폰 브라우저에서 최종 Phone APK를 받아 기존 앱 위에 **업데이트**하세요. 앱 삭제·데이터 삭제는 하지 마세요.

1. 기존 앱의 **기록 → 설정 → 앱 정보 및 라이선스 → 업데이트 → 새 버전 확인**을 누르거나 휴대폰에서 `CodexMeter-2.9.2-ko.apk`를 내려받습니다. Wear 파일은 시계용입니다.
2. 다운로드 폴더에서 APK를 누르고 **업데이트**를 선택합니다. 기존 앱을 삭제하거나 데이터를 초기화하지 마세요.
3. 설치 권한 안내가 나오면 현재 사용하는 브라우저/파일 앱에만 허용하고 설치 후 다시 끌 수 있습니다.
4. 홈의 주간 사용량과 기존 로그인·기록을 확인하고 **새로고침**을 누릅니다. 결제액을 등록했다면 누적 가성비와 지난 결산을 확인합니다.
5. 기존 업적·칭호 ON/OFF, 대표 메달·장착 칭호·XP·레벨·티어가 그대로인지 확인하세요. **이번 업데이트는 수집을 다시 초기화하지 않습니다.** 아직 수집을 시작하지 않았다면 성장에서 직접 ON으로 시작할 수 있습니다.
6. **성장 → 프로필 공유**에서 익명 카드 미리보기를 확인하고 필요하면 닉네임·날짜를 선택해 이미지 저장/공유를 누릅니다. 선택한 닉네임은 카드에 그대로 보입니다.
7. 대표 메달은 **업적 도감 → 대표 업적 편집**, 칭호는 **칭호 보관함**에서 직접 선택합니다. 별도 초기화는 **기록 → 설정 → 업적·칭호**에 있습니다. 초기화 확인 후 다시 ON으로 시작하며 이전 백업이 과거 수집을 되살리지 않습니다.
8. **기록 → 설정 → 위젯 및 화면 → 위젯 선택 → 사용량 + 작업현황**에서 통합 위젯을 추가하세요. 주간 잔여량과 작업현황을 함께 표시하며 기존 LAN/Tailscale 연결을 그대로 사용합니다. 권장 5×4, 높이를 늘리면 최대 6개 작업입니다.

Windows 0.1.10은 이번 버전에서 변경되지 않았으므로 이미 사용 중이면 재설치하지 않아도 됩니다. Windows 0.1.9 이상은 위젯 메뉴의 ⋯ → 업데이트 확인에서 0.1.10으로 업데이트할 수 있습니다. 처음 설치하거나 0.1.8 이하에서 바꾸는 경우에만 기존 위젯을 ⋯ → 종료하고 ZIP을 새 폴더에 모두 압축 풀어 `CodexMeterWidget.exe`를 실행합니다. `%LOCALAPPDATA%\CodexMeterWidget`은 지우지 마세요. Tailscale·PC 연결 설정은 기존 값을 유지합니다.

설치가 거부되면 설치된 버전과 오류 문구부터 확인하세요. 기존 한국어판과 같은 인증서로 서명했지만, 다른 제작자 앱 또는 더 높은 버전에는 바로 설치할 수 없습니다. 삭제로 우회하면 기록을 잃을 수 있습니다.

정식 업데이트 채널에 제공됩니다. 자동 확인 설정이 켜져 있으면 기존 확인 주기에 새 버전이 감지되며, 지금 확인하면 기다릴 필요가 없습니다. 다운로드·검증 후 Android의 설치 확인은 직접 눌러야 합니다.

이 배포물은 앱 삭제 후 자동 클라우드 복원을 제공하지 않습니다. 휴대폰의 실제 복구액·삼성 위젯·로그인·장시간 절전은 업데이트 후 확인해야 합니다.
