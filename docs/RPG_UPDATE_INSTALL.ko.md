# GPT HUD 2.8.23 설치·업데이트

1. 기존 앱의 **설정 → 업데이트 → 새 버전 확인**을 누르거나 휴대폰에서 `CodexMeter-2.8.23-ko.apk`를 내려받습니다. Wear 파일은 시계용입니다.
2. 다운로드 폴더에서 APK를 누르고 **업데이트**를 선택합니다. 기존 앱을 삭제하거나 데이터를 초기화하지 마세요.
3. 설치 권한 안내가 나오면 현재 사용하는 브라우저/파일 앱에만 허용하고 설치 후 다시 끌 수 있습니다.
4. 홈의 주간 사용량과 기존 로그인·기록을 확인하고 **새로고침**을 누릅니다. 결제액을 등록했다면 누적 가성비와 지난 결산을 확인합니다.
5. **성장**에서 대한민국/세계 티어, RPG 레벨, 요금제 인장을 눌러 상세보기를 열어보세요. 대표 업적 최대 3개와 장착 칭호를 설정할 수 있습니다. PC 토큰 연결은 기존 Windows Widget 0.1.7을 계속 사용합니다.

Windows: 기존 위젯을 ⋯ → 종료하고 ZIP을 새 폴더에 모두 압축 풀어 `CodexMeterWidget.exe`를 실행합니다. `%LOCALAPPDATA%\CodexMeterWidget`은 지우지 마세요. Tailscale·PC 연결 설정은 기존 값을 유지합니다.

설치가 거부되면 설치된 버전과 오류 문구부터 확인하세요. 기존 한국어판 2.8.22과 같은 인증서로 서명했지만, 다른 제작자 앱 또는 더 높은 버전에는 바로 설치할 수 없습니다. 삭제로 우회하면 기록을 잃을 수 있습니다.

정식 업데이트 채널에 제공됩니다. 자동 확인 설정이 켜져 있으면 기존 확인 주기에 새 버전이 감지되며, 지금 확인하면 기다릴 필요가 없습니다. 다운로드·검증 후 Android의 설치 확인은 직접 눌러야 합니다.
