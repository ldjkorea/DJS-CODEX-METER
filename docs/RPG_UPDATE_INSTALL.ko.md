# GPT HUD 2.8.21 설치·업데이트

1. 휴대폰에서 `CodexMeter-2.8.21-ko.apk`를 내려받습니다. Wear 파일은 시계용입니다.
2. 다운로드 폴더에서 APK를 누르고 **업데이트**를 선택합니다. 기존 앱을 삭제하거나 데이터를 초기화하지 마세요.
3. 설치 권한 안내가 나오면 현재 사용하는 브라우저/파일 앱에만 허용하고 설치 후 다시 끌 수 있습니다.
4. 홈의 주간 사용량과 기존 로그인·기록을 확인하고 **새로고침**을 누릅니다. 결제액을 등록했다면 누적 가성비와 지난 결산을 확인합니다.
5. **성장**에서 대한민국/세계 티어, XP, 현재 요금제 인장, 업적과 칭호를 확인합니다. PC 토큰을 받으려면 Windows Widget 0.1.7도 실행하고 기존 연결을 유지합니다.

Windows: 기존 위젯을 ⋯ → 종료하고 ZIP을 새 폴더에 모두 압축 풀어 `CodexMeterWidget.exe`를 실행합니다. `%LOCALAPPDATA%\CodexMeterWidget`은 지우지 마세요. Tailscale·PC 연결 설정은 기존 값을 유지합니다.

설치가 거부되면 설치된 버전과 오류 문구부터 확인하세요. 기존 한국어판 2.8.20과 같은 인증서로 서명했지만, 다른 제작자 앱 또는 더 높은 버전에는 바로 설치할 수 없습니다. 삭제로 우회하면 기록을 잃을 수 있습니다.

이 배포물은 앱 삭제 후 자동 클라우드 복원을 제공하지 않습니다. 휴대폰의 실제 복구액·삼성 위젯·로그인·장시간 절전은 업데이트 후 확인해야 합니다.
