# GPT HUD 2.8.25 설치와 성취 보관

1. 기존 GPT HUD에서 **설정 → 업데이트 → 새 버전 확인**을 누르세요. 또는 GitHub `ldjkorea/codex-meter-ko`의 **v2.8.25** 릴리스에서 **CodexMeter-2.8.25-ko.apk**를 받으세요.
2. 다운로드가 끝나면 APK를 열고 **업데이트**를 누르세요. Android가 설치 권한을 요청하면 현재 APK를 연 브라우저/파일 앱에만 허용하세요.
3. **기존 앱을 삭제하지 마세요.** 패키지와 서명이 같은 업데이트는 기존 저장소를 유지합니다. 설치 오류가 나면 앱 삭제·데이터 초기화로 해결하지 말고 오류 문구를 보관하세요.
4. 업데이트 후 로그인 상태, 주간 사용량, 성장 탭의 XP·칭호·대표 메달, 구독료 기록을 확인하세요. 홈 위젯도 한 번 갱신하세요.

## 휴대폰을 바꾸기 전에

- 로그인한 상태에서 **기록 → 설정 → 성취 백업·복원 → 암호 백업 저장**을 누르세요. 10~256자 암호를 두 번 입력하고 문서 선택창에서 파일을 저장합니다. 앱의 완료 안내까지 기다리세요.
- `.gpthud` 파일을 새 휴대폰으로 옮깁니다. 새 기기에서 **동일한 OpenAI 계정으로 로그인**한 뒤 **백업 가져오기**로 파일을 열고 같은 암호를 입력하세요.
- 암호를 잊으면 복원할 수 없습니다. 암호와 백업 파일을 안전하게 보관하세요. 백업에는 활동·결제 메타데이터가 포함되며 로그인 토큰과 대화 원문은 포함되지 않습니다.
- 반복 복원은 XP를 중복 지급하지 않습니다. 기존 최신 성취와 명시적으로 변경한 칭호·대표 메달·결제액을 우선 보존합니다. 손상되거나 다른 계정의 파일은 복원하지 않습니다.
- 이 파일은 **성취와 결제 결산**을 옮기는 기능입니다. 로그인, Tailscale 연결 비밀정보, 전체 앱 설정과 모든 과거 사용량 원장을 옮기는 파일은 아닙니다.
- 파일 선택 중 화면을 종료하거나 회전하여 암호 입력 상태가 사라지면 작업을 다시 시작하세요. 암호는 재생성 가능한 상태나 디스크에 저장하지 않습니다.

## 적용 범위

Android·Wear는 2.8.25 / versionCode 55입니다. Windows Widget은 기존 0.1.7을 그대로 사용합니다. 대한민국·세계 티어는 게임형 추정 평가이며, 시간대와 관측 범위를 입증할 수 없는 기록으로 사용자를 강등시키지 않습니다. 구독료 참고 환산값은 실제 API 청구액 또는 절약액이 아닙니다.

실제 삼성 갤럭시, 개인 계정 OAuth/API, 개인 기록 복구, Doze와 장시간 백그라운드 동작은 별도 실사용 확인이 필요합니다. 자동 업데이트 검사는 기존 설정을 따르며 Android 설치 확인은 직접 눌러야 합니다.
