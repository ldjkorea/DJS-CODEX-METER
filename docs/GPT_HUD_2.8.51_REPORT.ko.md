# GPT HUD 2.8.51 — 수집 새 출발 · 통합 위젯

## 변경과 데이터 범위

- 모든 계정에서 업적·칭호 수집을 한 번만 OFF·0으로 전환한다. 최초 계정 접근 시 트랜잭션으로 적용하며 재실행·재로그인 때 다시 초기화하지 않는다.
- 직접 ON으로 시작한 뒤의 확인된 활동만 집계한다. 업적·칭호는 독립적이며 OFF 기간을 소급하지 않는다.
- 이전 수집은 계정 문서의 `future.collection_archives`에 보관한다. 기존 자동 업적 보관함은 유지한다. 새 수집에는 이전 획득·장착 칭호와 대표 메달을 섞지 않는다.
- lifetime XP·레벨·현재/최고 티어·원본 토큰·SQLite 사용량·결제 결산·OAuth·PC 연결은 초기화하지 않는다. 이미 지급한 업적 XP ID도 유지하므로 같은 메달을 다시 얻어 XP를 중복 지급하지 않는다.
- 설정 → 업적·칭호에 업적/칭호 별도 초기화를 추가했다. 명시적 확인·계정 검사·안전 사본·트랜잭션 후 해당 수집만 OFF·0으로 되돌린다.
- 실제 백업 복원 경로가 처음 시작하지 않은 journey를 무조건 지워 과거 수집을 재주입하는 결함을 발견했다. 새 revision/reset 시각을 검사하고 기존 백업의 재유입을 막았다. 동일 계정의 새 수집 백업은 새 기기에 복원할 수 있다.
- 기존 53개 업적 ID/기본 조건과 63개 칭호를 유지한다. 새 수집에는 목표별 티어 전제조건을 추가하고 문양 색상을 해당 목표 티어에 맞춘다. 토큰 수집값·XP 공식·계정 한도는 바꾸지 않는다.

## 화면과 위젯

- 대표 업적은 업적 도감 안에서 편집한다. 칭호 랜덤 추천 버튼을 제거하고 미리보기 후 직접 장착한다.
- 한도 상세 바는 티어 색상으로 표시하되 빠른 사용 경고 문구는 유지한다. 색상을 낮은 농도로 적용해 숫자 대비를 보존한다.
- 달력은 확인된 일별 사용량에 빨강·주황·녹색·실버·골드 단계를 적용한다. 기록 없음과 실측 0은 다르며 한도별로 독립적이다. 날짜 선택·오늘 테두리·접근성 설명을 유지한다.
- 사용량은 정수로 표시하고 소수점 선택 메뉴를 제거한다. 원본 소수값과 계산 정밀도는 보존하며 사용률과 잔여율의 반올림 합계가 100이 되도록 한다.
- X 최신 글 진입 버튼을 제거했다. 저장된 인용·날짜·출처는 유지하며 자동 수집은 추가하지 않았다.
- 새로운 별도 Provider `CombinedStatusWidget`은 주간 잔여량 + Codex 작업현황을 표시한다. 권장 5×4, 기본 작업 4개, 높은 크기에서 최대 6개, 좁으면 1열이다.
- 기존 Provider ID·배치·옵션은 그대로다. 기존 인증·LAN/Tailscale·작업 저장소·조회 스케줄을 재사용한다. 연결 실패/오래된 상태는 회색으로 처리하며 백그라운드 15초 갱신을 보장하지 않는다.
- Windows 소스와 버전 0.1.10은 변경하지 않는다. 최신 Release만 읽는 기존 PC 업데이트 검사와 호환되도록 검증된 동일 ZIP을 함께 제공한다.

## 실제 검증

- `android/run-tests.sh`: 전체 JVM/source/SQLite/Windows 회귀 통과. 기존 fixture를 덮어쓰지 않고 정확한 검토 패치로 과거 보호 계약과 새 변경을 구분했다.
- CollectionRestartSelfTest: 94개 합성 검사 통과. 모든 계정 OFF·0, 독립 ON/OFF 4조합, 반복 이관, 별도 reset, 구 백업 차단, 원본 XP/티어 보존, 토큰 조건, 반올림을 검사했다.
- 실제 Android SQLite/Activity 검사: 31개 검사 통과. 별도 QA 패키지에서 이전 ON 계정 → OFF·0, ON 이후 획득·장착, 실제 Archive 복원, 별도 reset, 6개 합성 작업과 통합 RemoteViews를 검사했다. 사용자의 production 패키지·DB는 건드리지 않았다.
- UI: 실제 배포 Activity 코드의 56개 렌더·242개 검사 통과. 320/360/411/700dp, 글꼴 1.0/1.5/2.0, 한국어/영어, 라이트/다크 대표 조합이다. 모든 가능한 조합이나 물리 폴더블 인증은 아니다.
- 현재 화면에서 새 수집 0개·두 기능 OFF, 칭호 미장착, 한국어·영어 화면을 확인했다. 합성 ON 계정의 대표 메달·명시적 칭호 장착도 확인했다.
- Android/Wear Release 빌드·lint와 현지화·폰트/출처 검사를 통과했다. Git 소스 보안 검사도 최종 index를 대상으로 통과했다. APK 패키지/81/서명/체크섬은 최종 배포 manifest에 기록한다.
- 기존 lint baseline은 수정하지 않는다. 기존 오류/경고가 남아 있으며 lint task 통과를 전체 경고 0으로 표현하지 않는다. App 경고 261개(기준 247개), Wear 11개다. 기존 baseline의 오류 53개·경고 111개 필터 안내가 남는다. 신규 API 31 위젯 메타데이터의 하위 OS 무시 안내와 제거된 메뉴의 호환 리소스 등 비차단 경고를 포함하며 baseline을 확대하지 않았다.

## 미검증과 제한

- 실제 사용자 DB의 원격 초기화 완료를 확인한 것은 아니다. 설치 후 각 계정에 첫 접근할 때 새 정책이 적용된다.
- 실제 Galaxy 런처의 위젯 배치·크기 조절·Samsung AOD/Now Bar, Wear 장치, 실계정 OAuth/API, 외부망 Tailscale, Doze/재부팅·장기간 배터리는 미검증이다.
- RemoteViews의 합성 렌더링을 실제 런처나 PC↔휴대폰 실통신 성공으로 해석하지 않는다.
- 초기화는 새 수집을 시작하는 명시적 기능이다. 이전 장착 칭호·대표 메달은 새 수집에서 다시 획득 후 선택한다. lifetime 성취를 삭제하지 않는다.
- 저장된 이전 collection archive는 읽기 전용 안전 보존 자료이며 새 수집에 자동으로 합산하지 않는다.

## 설치와 소스 관리

기존 앱에서 기록 → 설정 → 앱 정보 및 라이선스 → 업데이트 → 새 버전 확인. 다운로드·검증 뒤 Android 설치 화면에서 업데이트를 누른다. 앱을 삭제하지 않는다. 자동 확인이 켜져 있으면 기존 검사 주기에 안내한다.

성장에서 업적/칭호를 각각 ON으로 시작한다. 설정의 위젯 선택에서 사용량 + 작업현황을 추가한다. Windows 0.1.10 사용자는 재설치할 필요가 없다.

현재 브랜치: `feature/collection-restart-combined-widget`. 기준 커밋 `eb496846548da99f4ae34b03116a5cc3501c3d4f`와 미커밋 `docs/emblem-concepts/`를 보존했다. 인증·SQLite 스키마·계정 사용량/결제 산식과 Windows 소스에는 변경이 없다. 최종 커밋·서명·파일 해시는 Release의 `release-manifest.json`과 `SHA256SUMS.txt`로 확인한다.
