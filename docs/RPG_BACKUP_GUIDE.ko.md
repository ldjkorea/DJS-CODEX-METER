# GPT HUD 기록 백업 안내

기기 교체 전 **기록 → 설정 → 계정 영역 → RPG 기록 백업·복원**을 엽니다. 화면의 암호화 백업 내보내기를 선택하고 Android 문서 선택 창에서 파일을 저장합니다. 사용자가 정한 암호는 별도로 안전하게 보관합니다. 암호를 잊으면 앱이 대신 해독할 수 없습니다.

새 기기에서는 먼저 같은 ChatGPT 계정으로 로그인한 뒤 백업·복원 화면에서 파일과 암호를 선택합니다. 계정이 다르거나 파일이 손상됐거나 암호가 틀리면 복원을 거부합니다. 실패했다고 앱을 삭제하거나 기존 기록을 지우지 마세요.

RPG 백업은 XP·성취·칭호·대표 메달·티어·결제 결산과 수집 시작 근거를 보존합니다. 일반 설정 백업이나 OAuth 로그인 전체 복원과는 다릅니다. 인증 토큰·PC 페어링 비밀·원본 대화·코드는 포함하지 않습니다. PC/Tailscale 연결은 새 기기에서 기존 비파괴 연결 안내를 따릅니다.

기존 앱 위에 설치하는 정상 업데이트와 앱을 삭제한 후 재설치는 다릅니다. 업데이트를 위해 앱을 삭제할 필요가 없습니다. 자동 클라우드 복원은 제공하지 않으므로 기기를 바꾸기 전에 직접 파일을 보관하세요. 반복 복원은 새 XP 지급이 아니며, 오래된 파일로 최신 성취를 낮추지 않는 기존 병합 정책을 사용합니다.

현재 내부 Phase D는 공개 업데이트가 아닙니다. 실제 새 휴대폰과 문서 선택 UI의 복원 성공 여부는 별도 검증 대상입니다. 개발 테스트 통과를 사용자 데이터의 실제 복구 완료로 해석하지 않습니다.
